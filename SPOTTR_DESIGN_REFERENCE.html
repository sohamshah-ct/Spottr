// Implementation Notes for Claude Code
Fonts
Import from Google Fonts: Syne (400–800) and Syne Mono. Use Syne for all UI text. Syne Mono for labels, timestamps, coordinates, monospace data.
CTA Buttons
Primary: background #00E676, color #000, borderRadius 16, fontWeight 800. Secondary: background #1E2530, color #A8A8B8. Never use purple or blue as primary action color.
Cards
All cards: background #0F1218, borderRadius 14, border: 1px solid rgba(255,255,255,0.06). Open lots get green border tint: rgba(0,230,118,0.18).
Availability Colors
Open spots: #00E676 text on rgba(0,230,118,0.10) bg. Filling: #FFB300 on rgba(255,179,0,0.10). Full: #FF3D57 on rgba(255,61,87,0.08).
Passive GPS Indicator
Small blinking green dot + "LOGGING PASSIVELY" in Syne Mono caps, ink3 color. Shows at top of home screen. Communicates silent data collection is active.
Satellite Toggle
Frosted pill at bottom of hero image. Dark semi-transparent background. "AI Map" and "Live Sat" options. Active tab gets background #0F1218. Inactive is transparent with muted text. Live dot animates on "Live Sat".
Row Cards
Selected row: borderColor #00E676 + subtle green bg tint. Unselected: transparent border. Each row shows: availability badge, row name, confidence level (High/Med/Est), Best tag if applicable, Maps deep link arrow.
Maps Deep Link
iOS: maps://maps.apple.com/?daddr={lat},{lng}&dirflg=d. Android: https://maps.google.com/?q={lat},{lng}&mode=driving. Routes to exact row entrance coordinate, not lot address.
Driving Screen
Map background with semi-transparent ETA card floating at top. Live monitoring strip at bottom above step card. Blinking green dot in monitoring strip. Car emoji animated along route path.
