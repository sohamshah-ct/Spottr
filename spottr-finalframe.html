01 · PHILOSOPHY

Why this looks the way it does

Spottr is a utility tool, not an entertainment app. The aesthetic earns its keep by being honest, fast, and out of the way.

01
Dark-first surface
OLED-black is canonical. Reduces driver distraction at night, preserves battery, gives the accent maximum visual weight.
02
Single accent discipline
One color carries meaning across the entire app. The user learns one rule and trusts it everywhere.
03
Honest by sentence
Freshness is communicated through plain language, not colored pills. "3 min ago" and "typical for now" tell the truth about confidence.

ApproachScreen.tsx
SCREEN 07

Approach view

The screen that doesn't exist in any other parking app. Fires automatically when GPS detects the user has crossed the lot polygon. Apple Maps says "you have arrived"; Spottr takes over with this.

Close-up aerial of the lot. Building at top, three rows of parking, drive aisles. Gray rectangles are parked cars; the empty space in the top-right is where 12 open spots cluster. User's pulsing dot enters at bottom-left. The accent box outlines the open zone. The animated dashed path flows from user to zone.

One short instruction the driver can read at a glance. No turn-by-turn voice; lots are too small. The visual works at lot speed.

  • TRIGGERGeofence check against lot polygon. Fires within 50ms of crossing. Haptic tap on entry.
  • PATHAnimated dashed line, server-computed from entry to zone centroid.
  • VOICENo in-app voice. CarPlay/Siri handles voice natively if user wants it.

Parked

The user tapped "I parked" from the approach screen. Spottr captured their lat/lng + timestamp, generated a human-readable description, saved it. When they return, this is the screen.

04 · ROADMAP

The path to specific-spot routing

MVP delivers zone-level routing. Each subsequent layer tightens the precision. BestTime layers on within weeks because the API key is already in hand. Parkopedia and V7 layers are gated on partnerships and capital, not engineering.

MVP · LAYER 1
SHIPS 2–3 WEEKS
Satellite CV — zone-level
Modal-deployed YOLO + SAM2 on Mapbox tiles. Zone-level aggregation. User sees the zone where open spots cluster.
V6 · LAYER 2
~1 WEEK POST-MVP
BestTime integration
API key in hand. 2–3 days of backend work. Live + forecast busyness for Costco-class venues.
V6.5 · LAYER 2.5
1–3 MONTHS
Parkopedia partnership
Partnered garage occupancy. Gated on sales contract negotiation.
V7-A · LAYER 3
6–12 MONTHS
Connected-vehicle telemetry
Wejo, INRIX, or HERE license. Row-level precision. Gated on capital.
V7-B · LAYER 4
DAY 1 → COMPOUNDS
User crowdsourcing
"I parked" + Bluetooth-disconnect events feed the model. Value compounds with user base.
V7-C · LAYER 5
6–12 MONTHS
Owned cameras at flagship lots
50–200 highest-value lots. True spot-level. "Spot 14 is open, take me there."
